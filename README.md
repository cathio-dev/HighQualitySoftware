# Software Engineering

This repository serves as a collection of projects, assignments, and practical exercises developed as part of the Software Engineering course.

The purpose of this repository is to document my learning journey while applying software engineering principles through hands-on development. The implementations emphasize code quality, maintainability, readability, documentation, and industry best practices.

### Topics Covered
- Software Development Lifecycle (SDLC)
- Requirements Engineering
- Object-Oriented Design
- Design Patterns
- Version Control with Git & GitHub
- Testing and Quality Assurance
- Software Architecture
- Clean Code Principles
